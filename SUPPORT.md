# Support

GogglesView is a free, volunteer-maintained project. Here is how to get help.

1. Read the Troubleshooting section in the [README](README.md#troubleshooting). Most connection problems (goggles not detected, no picture, helper not approved) are covered there.
2. Generate a diagnostics report in Settings > Advanced. It collects app, helper and device details without secrets.
3. Search the [existing issues](https://github.com/Kristian-Buriasco/gogglecast/issues) for the same problem.
4. If nothing matches, [open an issue](https://github.com/Kristian-Buriasco/gogglecast/issues/new/choose) and paste the diagnostics report. Say which goggles firmware and macOS version you use.

Security problems are not handled in public issues. Follow [SECURITY.md](SECURITY.md).

For setup and signing questions when building from source, see [docs/dev-setup.md](docs/dev-setup.md).
